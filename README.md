# Дуу Салгагч

Монгол хэлтэй веб. Файл оруулж хоолой, хөгжмийг Demucs htdemucs загвараар салгана. Гаралт бүрийг браузерт сонсож, 320 kbps MP3-аар татна. YouTube холбоос нь бичлэгийг YouTube дээр нээдэг. Өөрийн бичлэгийг Studio-оос экспортолж оруулж болно.

## Docker-оор ажиллуулах

```sh
docker build -t duu-salgagch .
docker run --rm -p 8080:8080 duu-salgagch
```

http://localhost:8080 хаягаар нээнэ. Docker build үед PyTorch болон загварын жинг татна. Контейнерийг нэг instance, нэг Gunicorn worker-тэй ажиллуулна. Эхний байдлаар 2 vCPU, 4 ГБ RAM-аар бодит дуунууд дээр хэмжилт хийнэ.

50 МБ болон 10 минутын хязгаартай. Нэг боловсруулалт зэрэг ажиллана. Ажил дууссанаас нэг цагийн дараа үр дүн автоматаар устна. Контейнер дахин асахад боловсруулалтын холбоос хүчингүй болно. Үр дүнгийн холбоосыг мэддэг хүн файлыг нээж чадна.

Нийтийн хостинг дээр Dockerfile-ийг ашиглаж PORT орчны хувьсагчаар портыг тохируулна.

## PWA

Суулгахын тулд HTTPS хаяг эсвэл localhost ашиглана. Chrome болон Edge дээр апп суулгах боломжтой үед “Апп суулгах” товч гарна. iPhone дээр Safari-ийн “Add to Home Screen” цэсээр нэмнэ.

Анх онлайн нээсний дараа холболт тасарвал тусгай дэлгэц гарна. Аудио боловсруулах, сонсох, татах үйлдэлд серверийн холболт шаардлагатай. Хөтчийн PWA кэшид аудио болон боловсруулалтын үр дүн хадгалагдахгүй.

Dockerfile дэмждэг хостод репог холбоно. Flask, FFmpeg, PyTorch ажиллуулах контейнер шаардлагатай.
